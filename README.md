# Uniqe Design — Premium Graphic Portfolio App

A redesigned Android portfolio app based on the supplied Uniqe Design logo, UI reference, and feature requirements.

## Included
- Premium dark/light visual system
- Home dashboard and featured projects
- Portfolio search, categories and sorting
- Add/remove projects
- Services list with add/remove controls
- Designer profile and contact details
- Email, phone, Telegram and Google Maps actions
- Display/image quality/color profile settings
- Layout, category and sorting preferences
- Availability status
- Watermark and download protection toggles
- Resume/image upload launcher
- Social/portfolio management sections
- Brand controls for logo/name/colors/slogan
- English / አማርኛ language option placeholder
- GitHub Actions workflow that builds an APK without Android Studio

## Build on GitHub
Push the project to a GitHub repository. The workflow in `.github/workflows/build-apk.yml` builds `app-debug.apk` and uploads it as `Uniqe-Design-APK`.
